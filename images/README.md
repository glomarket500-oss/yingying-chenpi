## 📸 拍摄建议

### 陈皮产品拍摄要点
1. **光线**：自然光或柔和人工光，避免强光直射
2. **背景**：纯色背景（米白/浅棕/木质），突出产品
3. **角度**：俯视45°角，展示油室和纹理
4. **细节**：拍摄油室特写、内瓤纹理、折断面
5. **场景**：可搭配茶具、茶壶，增加生活感

### 产地拍摄要点
1. **全景**：果园全景，展示新会水乡风貌
2. **特写**：茶枝柑果实、采摘过程
3. **人文**：果农劳作、传统开皮工艺
4. **地标**：村口石碑、地理标志牌
5. **气候**：银洲湖畔、三江汇流景观

### 干仓拍摄要点
1. 整齐堆放的陈皮（棉麻袋/陶罐）
2. 温湿度监控设备
3. 定期翻晒场景

## 🎨 替代方案

如果暂时没有实拍照片，可以使用以下方式：

1. **AI生成图片**：使用 Midjourney / Stable Diffusion 生成陈皮主题图片
2. **免费图库**：
   - Unsplash (unsplash.com)
   - Pexels (pexels.com)
   - Pixabay (pixabay.com)
3. **注意**：免费图库图片需确认商用授权
